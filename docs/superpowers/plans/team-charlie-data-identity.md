# Team Charlie — Data & Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Prisma schema, DAL with authorization, Clerk authentication proxy, and Clerk webhook sync for LiveFlows MVP 1a.

**Architecture:** Prisma 7 with `@prisma/adapter-pg` driver adapter stores Users, Workspaces, Members, Projects, and CanvasSnapshots. Authorization lives exclusively in the DAL (`src/server/dal/`), never in the proxy. The proxy (`proxy.ts`) handles authentication only — redirecting unauthenticated users. Clerk webhooks sync identity state to Postgres idempotently.

**Tech Stack:** Prisma 7.9.1, @prisma/adapter-pg 7.9.1, pg 8.22.0, @clerk/nextjs 7.7.1, Next.js 16.3.0, Vitest 4.1.10, Zod 4.4.3

## Global Constraints

- **Package manager:** pnpm 11.20.0 only. Never npm or yarn.
- **Linter/formatter:** Biome 2.4.2 only (`pnpm lint`, `pnpm format`). Never ESLint/Prettier.
- **Prisma generator:** `provider = "prisma-client"` (NOT `prisma-client-js`). Output to `../src/generated/prisma`.
- **Prisma driver adapter:** mandatory. `@prisma/adapter-pg` with `PrismaPg({ connectionString })`.
- **Prisma config:** `prisma.config.ts` at root. Import `defineConfig` from `@prisma/config`. Includes `experimental: { adapter: true }` and `engine: 'js'`.
- **Module format:** Determined by G0 gate. Read the outcome from `docs/superpowers/spikes/README.md` before starting any task. If `"type": "module"` was chosen, no further action; if `moduleFormat = "cjs"` was chosen, ensure the Prisma generator includes that field.
- **Proxy file:** `proxy.ts` (NOT `middleware.ts`). Export function named `proxy` or default export. Next.js 16 convention.
- **Auth:** `auth()` is always awaited. Use `isAuthenticated` (not `!!userId`).
- **Clerk roles:** opaque strings. `org:admin` and `org:member` are defaults only — never validate against a closed set.
- **Migrations:** additive only. Previous release must still run against the new schema.
- **Tests:** Vitest. Unit tests never use `DATABASE_URL`. Integration tests use `docker-compose.test.yml` throwaway Postgres.
- **Authorization boundary:** DAL only, never the proxy. Non-members receive NotFound, never Forbidden.
- **Session authority:** `orgId` and `orgSlug` from `auth()` are the authority. URL slug is only a label.

**Authorization rules (binding — implement exactly):**

1. Authorization lives in the DAL and NEVER in the proxy. The proxy does authentication only.
2. The session (`auth()`) is the authority for the active organization. `orgId` always comes from `auth()`, never from client input.
3. The URL slug is only a label. Every DAL entry point asserts `orgSlug === slugFromUrl`. If they differ, redirect to the correct slug.
4. A user in a different workspace must receive NotFound, not Forbidden — do not leak resource existence.
5. Membership is a join condition, not a separate check. There is no code path that returns a project without proving membership in the same query.
6. Webhooks reconcile; they never gate. The lazy upsert covers the acting user.
7. `redirect()` throws. Nothing after it runs.
8. Clerk organization roles are opaque strings. `org:admin` and `org:member` are only defaults — never validate against a closed set. Store and propagate as `String`.

**Room lifecycle rules (binding):**

- `createProject` calls `provisionRoom` from `src/server/liveblocks.ts` after creating the DB row. If `provisionRoom` fails, delete the Project row and surface the error.
- `deleteProject` calls `decommissionRoom` before deleting the DB row. If `decommissionRoom` fails, log at warn and proceed with the Postgres delete.
- Until Delta's D1 merges, `src/server/liveblocks.ts` contains a stub that THROWS — never returns fake data.

```ts
import { auth } from '@clerk/nextjs/server'
import { redirect } from 'next/navigation'
import { db } from '../db'
import { UnauthorizedError } from './errors'

export type WorkspaceRef = { id: string; slug: string }

/**
 * Asserts session, asserts orgSlug === slugFromUrl, lazy-upserts.
 * Redirects on failure — redirect() throws, nothing after it runs.
 */
export async function requireWorkspace(slugFromUrl: string): Promise<WorkspaceRef> {
  const { isAuthenticated, userId, orgId, orgSlug } = await auth()

  if (!isAuthenticated || !orgId) {
    redirect('/sign-in')
  }

  // The session is the authority. The URL slug is only a label.
  if (orgSlug !== slugFromUrl) {
    redirect(`/w/${orgSlug}`)
  }

  // Lazy upsert — never block onboarding on webhook delivery
  const workspace = await db.workspace.upsert({
    where: { clerkOrgId: orgId },
    update: {},
    create: { clerkOrgId: orgId, name: orgSlug!, slug: orgSlug! },
    select: { id: true, slug: true },
  })

  return workspace
}

/**
 * For route handlers with no slug in the path (e.g., liveblocks-auth).
 * Throws UnauthorizedError on failure.
 */
export async function requireWorkspaceByOrgId(orgId: string): Promise<WorkspaceRef> {
  const { isAuthenticated, orgId: sessionOrgId } = await auth()

  if (!isAuthenticated || !sessionOrgId || sessionOrgId !== orgId) {
    throw new UnauthorizedError()
  }

  const workspace = await db.workspace.upsert({
    where: { clerkOrgId: orgId },
    update: {},
    create: { clerkOrgId: orgId, name: orgId, slug: orgId },
    select: { id: true, slug: true },
  })

  return workspace
}
```

```ts
import { auth } from '@clerk/nextjs/server'
import { notFound } from 'next/navigation'
import { db } from '../db'
import { requireWorkspace } from './workspaces'
import { provisionRoom, decommissionRoom, roomIdForProject } from '../liveblocks-stub'

export type ProjectListItem = {
  id: string
  name: string
  updatedAt: Date
}

export type ProjectDetail = ProjectListItem & { liveblocksRoomId: string }

/**
 * Lists all projects in the workspace. Proves membership via requireWorkspace.
 */
export async function listProjects(workspaceSlug: string): Promise<ProjectListItem[]> {
  const workspace = await requireWorkspace(workspaceSlug)

  const projects = await db.project.findMany({
    where: { workspaceId: workspace.id },
    select: { id: true, name: true, updatedAt: true },
    orderBy: { updatedAt: 'desc' },
  })

  return projects
}

/**
 * Gets a single project. Non-members receive NotFound, not Forbidden.
 */
export async function getProject(workspaceSlug: string, projectId: string): Promise<ProjectDetail> {
  const workspace = await requireWorkspace(workspaceSlug)

  const project = await db.project.findFirst({
    where: { id: projectId, workspaceId: workspace.id },
    select: { id: true, name: true, updatedAt: true, liveblocksRoomId: true },
  })

  if (!project) {
    notFound()
  }

  return project
}

/**
 * Creates a project and provisions its Liveblocks room.
 * If room provisioning fails, rolls back the Project row.
 */
export async function createProject(workspaceSlug: string, name: string): Promise<ProjectDetail> {
  const workspace = await requireWorkspace(workspaceSlug)
  const { userId, orgId } = await auth()

  const project = await db.project.create({
    data: {
      name,
      workspaceId: workspace.id,
      liveblocksRoomId: '', // placeholder, updated below
      createdById: userId!,
    },
    select: { id: true, name: true, updatedAt: true, liveblocksRoomId: true },
  })

  const roomId = roomIdForProject(project.id)

  try {
    await provisionRoom({
      roomId,
      workspaceId: workspace.id,
      clerkOrgId: orgId!,
    })

    // Update the project with the real room ID
    const updated = await db.project.update({
      where: { id: project.id },
      data: { liveblocksRoomId: roomId },
      select: { id: true, name: true, updatedAt: true, liveblocksRoomId: true },
    })

    return updated
  } catch (error) {
    // Roll back: delete the project row if room provisioning fails
    await db.project.delete({ where: { id: project.id } })
    throw error
  }
}

/**
 * Deletes a project and decommissions its Liveblocks room.
 * Decommission is best-effort — log and proceed on failure.
 */
export async function deleteProject(workspaceSlug: string, projectId: string): Promise<void> {
  const workspace = await requireWorkspace(workspaceSlug)

  const project = await db.project.findFirst({
    where: { id: projectId, workspaceId: workspace.id },
    select: { id: true, liveblocksRoomId: true },
  })

  if (!project) {
    notFound()
  }

  // Decommission room first — best effort
  try {
    await decommissionRoom(project.liveblocksRoomId)
  } catch (error) {
    console.warn(`Failed to decommission room ${project.liveblocksRoomId}:`, error)
  }

  await db.project.delete({ where: { id: project.id } })
}

/**
 * Gets a project with its canvas snapshot elements for the read-only outage fallback.
 * Returns snapshotElements (defaulting to []) for CanvasRoom's fallbackElements prop.
 *
 * ADDITION TO FROZEN CONTRACT (plan-fix-time 2026-08-08): This function was not in
 * the original delivery graph §6 frozen interface. It is required by Echo E2 to satisfy
 * DoD criterion 6 (Liveblocks-outage read-only path). Added here so that both Charlie
 * (producer) and Echo (consumer) code against an identical signature.
 */
export type ProjectWithSnapshot = {
  id: string
  name: string
  updatedAt: Date
  liveblocksRoomId: string
  snapshotElements: unknown[]  // CanvasSnapshot.elements — may be [] if never synced
}

export async function getProjectWithSnapshot(
  workspaceSlug: string,
  projectId: string,
): Promise<ProjectWithSnapshot> {
  const workspace = await requireWorkspace(workspaceSlug)

  const project = await db.project.findFirst({
    where: { id: projectId, workspaceId: workspace.id },
    select: {
      id: true,
      name: true,
      updatedAt: true,
      liveblocksRoomId: true,
      canvas: { select: { elements: true } },
    },
  })

  if (!project) {
    notFound()
  }

  return {
    id: project.id,
    name: project.name,
    updatedAt: project.updatedAt,
    liveblocksRoomId: project.liveblocksRoomId,
    snapshotElements: (project.canvas?.elements as unknown[]) ?? [],
  }
}
```

**Webhook rules (binding):**

4. All handlers are **idempotent** because Clerk retries. Idempotency is enforced via the `ProcessedWebhook` table keyed on the `svix-id` header.
5. Clerk roles are opaque strings — stored as-is in `WorkspaceMember.role`, never validated against a closed set.

```ts
import { verifyWebhook } from '@clerk/nextjs/webhooks'
import { NextRequest } from 'next/server'
import { db } from '@/server/db'

export async function POST(req: NextRequest) {
  let evt: Awaited<ReturnType<typeof verifyWebhook>>

  try {
    evt = await verifyWebhook(req)
  } catch (err) {
    console.error('Clerk webhook verification failed:', err)
    return new Response('Bad signature', { status: 400 })
  }

  // Idempotency: deduplicate on svix-id header
  const svixId = req.headers.get('svix-id')
  if (!svixId) {
    return new Response('Missing svix-id', { status: 400 })
  }

  try {
    await db.processedWebhook.create({
      data: { id: svixId, source: 'clerk' },
    })
  } catch {
    // Unique constraint violation = already processed
    return new Response('Already processed', { status: 200 })
  }

  try {
    switch (evt.type) {
      case 'user.created':
      case 'user.updated':
        await handleUserUpsert(evt.data)
        break

      case 'user.deleted':
        await handleUserDeleted(evt.data)
        break

      case 'organization.created':
      case 'organization.updated':
        await handleOrgUpsert(evt.data)
        break

      case 'organizationMembership.created':
      case 'organizationMembership.updated':
        await handleMembershipUpsert(evt.data)
        break

      case 'organizationMembership.deleted':
        await handleMembershipDeleted(evt.data)
        break

      default:
        // Unknown event type — acknowledge to prevent retries
        break
    }
  } catch (err) {
    console.error(`Clerk webhook handler error for ${evt.type}:`, err)
    return new Response('Handler error', { status: 500 })
  }

  return new Response('OK', { status: 200 })
}

async function handleUserUpsert(data: any) {
  const { id, email_addresses, first_name, last_name, image_url } = data
  const primaryEmail = email_addresses?.find((e: any) => e.id === data.primary_email_address_id)

  await db.user.upsert({
    where: { id },
    update: {
      email: primaryEmail?.email_address ?? '',
      name: [first_name, last_name].filter(Boolean).join(' ') || null,
      avatarUrl: image_url ?? null,
    },
    create: {
      id,
      email: primaryEmail?.email_address ?? '',
      name: [first_name, last_name].filter(Boolean).join(' ') || null,
      avatarUrl: image_url ?? null,
    },
  })
}

async function handleUserDeleted(data: any) {
  const { id } = data
  if (!id) return

  // Cascade will handle WorkspaceMember deletion
  await db.user.delete({ where: { id } }).catch(() => {
    // Already deleted or never existed — idempotent
  })
}

async function handleOrgUpsert(data: any) {
  const { id, name, slug } = data

  await db.workspace.upsert({
    where: { clerkOrgId: id },
    update: { name: name ?? id, slug: slug ?? id },
    create: { clerkOrgId: id, name: name ?? id, slug: slug ?? id },
  })
}

async function handleMembershipUpsert(data: any) {
  const { organization, public_user_data, role } = data
  const orgId = organization?.id
  const userId = public_user_data?.user_id

  if (!orgId || !userId) return

  // Ensure workspace exists (may arrive before organization.created)
  const workspace = await db.workspace.upsert({
    where: { clerkOrgId: orgId },
    update: {},
    create: { clerkOrgId: orgId, name: orgId, slug: orgId },
    select: { id: true },
  })

  // Ensure user exists (may arrive before user.created)
  await db.user.upsert({
    where: { id: userId },
    update: {},
    create: { id: userId, email: '' },
  })

  // Upsert the membership — role is an opaque string, never validated
  await db.workspaceMember.upsert({
    where: { userId_workspaceId: { userId, workspaceId: workspace.id } },
    update: { role: role ?? 'org:member' },
    create: { userId, workspaceId: workspace.id, role: role ?? 'org:member' },
  })
}

async function handleMembershipDeleted(data: any) {
  const { organization, public_user_data } = data
  const orgId = organization?.id
  const userId = public_user_data?.user_id

  if (!orgId || !userId) return

  const workspace = await db.workspace.findUnique({
    where: { clerkOrgId: orgId },
    select: { id: true },
  })

  if (!workspace) return

  await db.workspaceMember.deleteMany({
    where: { userId, workspaceId: workspace.id },
  })
}
```

## Appendix: Findings and open questions

### Verified against installed packages / Context7

1. **Prisma 7 `prisma.config.ts`:** The import is `import { defineConfig } from '@prisma/config'` (NOT `from 'prisma/config'` as the spec §5 states). The spec's example shape (`adapter:` and `migrations: { adapter: }` as top-level fields) does NOT match the verified shape from `prisma@7.9.1` source, which uses `experimental: { adapter: true }`, `engine: 'js'`, and `async adapter()` function. **However, since another agent owns `prisma.config.ts` (G0 gate), this plan does not write it.** The G0 agent must resolve the exact field names.

2. **Clerk `verifyWebhook`:** Confirmed — `import { verifyWebhook } from '@clerk/nextjs/webhooks'`, takes `req: NextRequest` directly. Reads `CLERK_WEBHOOK_SIGNING_SECRET` from env automatically.

3. **Clerk `auth()`:** Returns `{ isAuthenticated, userId, orgId, orgSlug, orgRole, ... }`. Note: `orgSlug` may be `undefined` if the org has no slug set in Clerk. The DAL should handle this edge case (the spec assumes it is always set when an org is active).

4. **Next.js 16 proxy:** File is `proxy.ts`, export is named `proxy` or default. Clerk's `clerkMiddleware()` is compatible as a default export. The config matcher syntax is identical to the old middleware.

5. **ClerkProvider `taskUrls`:** Confirmed — `taskUrls={{ 'choose-organization': '/session-tasks/choose-organization' }}`.

### Underspecified in the delivery graph / spec

1. **`orgSlug` being undefined:** The spec's `requireWorkspace` uses `orgSlug!` (non-null assertion) but the Clerk Auth object shows `orgSlug: undefined` in examples. If an org has no slug, the redirect `redirect(`/w/${orgSlug}`)` produces `/w/undefined`. The implementation should handle this — possibly by looking up the workspace by orgId and using the stored slug. This is a spec gap.

2. **`requireWorkspaceByOrgId` creation data:** When lazy-upserting with only an `orgId` (no slug available from the request), what slug and name should be used for `create`? The spec does not address this. This plan uses the orgId as a temporary placeholder, expecting the `organization.created` webhook to correct it shortly after.

3. **`Project.createdById` sourcing in `createProject`:** The spec says `createdById` has no relation to User (audit field only), but `auth()` returns `userId` which is the Clerk user ID. This is consistent, but the DAL must call `auth()` a second time inside `createProject` to get `userId` (since `requireWorkspace` only returns the workspace). Alternatively, `requireWorkspace` could return `userId` too — but that changes the frozen interface. This plan calls `auth()` twice, which is acceptable since `auth()` reads from request context, not the network.

4. **`liveblocksRoomId` initial value:** `createProject` creates the row first (to get the cuid), then provisions the room. The `liveblocksRoomId` column has a `@unique` constraint, so the initial empty-string placeholder could conflict. A better approach may be to generate the cuid client-side or use a two-phase approach. This plan uses an empty string then updates, but notes it as a potential unique-constraint issue if two projects are created simultaneously.
