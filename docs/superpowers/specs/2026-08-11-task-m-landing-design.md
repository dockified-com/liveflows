# Task M: Landing Page Design

**Date:** 2026-08-11
**Status:** Approved
**Scope:** MVP 1a (Task M)

## 1. Overview
A public `/` route marketing page for LiveFlows. It must explain what the product is and provide entry points to sign in or sign up.

## 2. Implementation
*   **File:** `src/app/(marketing)/page.tsx`
*   **Design:** Modern, clean, dark-mode SaaS aesthetic. Glassmorphism, gradients.
*   **Content:**
    *   Hero section: "Collaborative System Design in Realtime."
    *   Call to action buttons: "Get Started" (routes to `/sign-up`) and "Sign In" (routes to `/sign-in`).
    *   Feature highlights: Realtime sync, strict workspace isolation.
*   **Code:** Use Tailwind v4. Do NOT use external UI libraries.

## 3. Testing
*   Verify unauthenticated users can view the page.
